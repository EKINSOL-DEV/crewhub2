# M3 — Build It Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Two Point core loop — lay out your own campus: place furniture and decor on a snap grid, draw building footprints that come with desks, and have the robots actually use what you build. Everything persists.

**Architecture:** New `src/game/build/` (edit store + pure layout merging + in-canvas placement tools + HTML palette). Persistence via the settings KV (`commands.getSetting/setSetting`, key `game.campus.edits`) — the established v2 pattern (`src/panels/world/props/store.ts`); real SQLite tables can come later with multi-campus (documented deviation from the spec's "world-layout tables": zero backend changes keeps M3 frontend-only and the JSON blob migrates trivially). The sim gains `updateWorld(grid, buildings)` so edits re-plan robots without respawning them.

**Tech Stack:** unchanged. No new dependencies.

### Task 2: `Sim.updateWorld` — edits re-plan robots without respawning

**Files:** Modify `src/game/sim/sim.ts`, `sim.test.ts`.

**Interfaces:** `Sim` gains `updateWorld(grid: NavGrid, buildings: Building[]): void` — swaps grid+buildings, clears every bot's `path`, releases ALL desk reservations (deskOwners cleared, deskId nulled), then re-plans each bot from its CURRENT position per its existing status (Working bots grab desks from the NEW pool). Bots never teleport.

**Steps (TDD):** tests — (a) after updateWorld with an extra placed building, a 17th Working bot that was overflow gets a real desk; (b) positions unchanged at the swap tick; (c) desks from removed buildings are released and their sitters re-plan; (d) determinism preserved. → implement (reuse the existing per-status plan helpers) → full sim suite green → commit.

**Details:**

- Ground picking: one invisible plane mesh (`onPointerMove/onPointerDown`) spanning the campus; snap cursor pos.
- Item tool: semi-transparent ghost (the model via `useModel`, opacity via a cloned transparent toon material OR a simple ring marker + model at 0.6 opacity — pick simpler, document); green/red tint by `canPlaceItem`; click places (`addItem`), `[`/`]` rotates the pending rot, ESC → select tool → second ESC exits build mode.
- Building tool: first click anchors, drag/second-click sets the opposite corner; live rect outline (thin box mesh) green/red by `canPlaceBuilding`; on confirm → `addBuilding` (roomId null; room linking is Task 5's dialog).

- Keyboard handling lives on the GameShell wrapper div (tabIndex 0), mirroring the old WorldPanel pattern (cite).
- Camera: `enabled={!buildActive || tool.kind === "select"}` — pan allowed in select, disabled while placing (wheel zoom always on).
- Smoke test: with mocked stores + mode store preset to item tool, pointer events on the ground plane place an item (assert store call); rotate/delete key paths unit-tested against the mode/edits stores directly where the canvas is awkward — document coverage split.
